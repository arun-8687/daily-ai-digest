By Hermes·Executive Summary

The Day in Review

This week's Substack content captured a genuine inflection point in AI-assisted software development. Three independent narratives converge: Mythos-class models (Claude 5 Fable) are now running autonomous multi-hour coding sessions with minimal human oversight, Anthropic published internal telemetry showing AI writes 80%+ of its shipped code, and GitHub disclosed that agent-generated code grew 1,400% in 2026 — straining infrastructure originally designed for human-paced development.

But the most valuable content this week comes from the critical voices, not the boosters. Justin Johnson (Run Data Run) read the footnotes buried in Anthropic's RSI white paper and found the headline numbers (8× productivity, 80% AI-authored code) contain gaping caveats the press coverage ignored. Ethan Mollick, after hands-on testing of Claude Fable, describes feeling less like a wizard and more like a "patron" — commissioning work he cannot observe being done. The through-line is clear: AI coding capability is accelerating faster than our ability to measure, trust, or govern it, and engineering leaders need frameworks for weighing vendor claims against operational reality.

What it feels like to work with Mythos

First hands-on testing of Claude 5 Fable (the first public Mythos-class model). Mollick documents autonomous multi-hour sessions where Fable launched sub-agents to research travel data (2,200 flights, rail schedules, road speeds from academic papers), coded simultaneously, and produced a working isochrone map from a single vague prompt. The model worked 9.5 hours uninterrupted on a complex research software project. The human role collapsed from "wizard" to "patron" — describing intent, paying tokens, judging the output, but no longer steering the process.

"With Fable the spell has gotten powerful enough that I am no longer sure I am the wizard. I am closer to a patron. I describe what I want, I pay for it, and I judge the result. The conjuring happens somewhere I cannot watch."

AI Is Building AI. Now Read the Footnotes.

Definitive critical analysis of Anthropic's widely-cited RSI white paper. Johnson extracts the caveats buried in the footnotes that virtually every press coverage omitted: "80% of merged code authored by Claude" measures lines, not decisions — a junior under senior direction also types a lot of lines. "Engineers ship 8× more code per day" is conceded by Anthropic to be "almost certainly an overstatement of the true productivity gain." And the critical counter-data: METR's controlled trial of experienced devs with AI tools showed they felt 20% faster but were measured 19% slower. This is the single most useful data point in the entire piece.

"Felt twenty percent faster. Measured nineteen percent slower. That gap is the number to carry out of this essay."

GitHub's Plan for Agents — Kyle Daigle, GitHub

GitHub COO Kyle Daigle reveals unprecedented platform strain from agentic coding: commits surged from 1 billion in 2025 to 275 million per week (on pace for 14 billion in 2026). Agent-generated code grew 1,400% in 2026. GitHub Actions grew from 500M minutes/week in 2023 to 1B/week in 2025. Daigle discusses GitHub's response: WorkIQ, MCP integration, micro-skills replacing mega-skills, Copilot evolving from completion → CLI → desktop app → cloud agents, and the fundamental question of whether CI/CD and human code review can keep up when every idea becomes a build.

"Platform activity is surging. There were 1 billion commits in 2025. Now it's 275 million per week, on pace for 14 billion this year."

Opus 4.8 and Workflows — One Careful Pass Is No Longer the Default

Anthropic's Opus 4.8 price cut (3× cheaper Fast mode: $10/$50 per million tokens) combined with Dynamic Workflows (JavaScript orchestration where the model writes its own fan-out scripts with parallel sub-agents and adversarial verifiers) fundamentally changes the economics of agentic code review. Fifty parallel review passes now cost what one used to. The "adversarial verify" pattern — spawn three independent skeptics per finding, kill the finding if a majority refute it — shows Anthropic selling fan-out as more checks, not more answers.

"The bridge between one model call and agentic system is now a tool the model writes for itself, in JavaScript, with caching and resume baked in."

The Skill That Edits Its Own Instructions

Self-editing skills — agent instructions that reflect on their own performance and update themselves — are emerging as the new unit of ownership in AI engineering. The "skill" (a plain-text instruction file) is the part your team owns; the model is rented and swapped every few months. There are now 1.6 million skill files on public GitHub, up from 790K six months ago. The open skill standard now runs across Claude Code, Codex, Cursor, Copilot, and 30+ tools. But most skills "barely trigger or quietly burn context" — self-editing compounds whatever the skill already was, noise included.

"The model is rented, and it gets swapped for a better one every few months. The skill is the part you own."
By Hermes·Signals

Trending Themes

  • The patience problem: Every major publication this week tells the same story — AI coding output is exploding, but the bottleneck is now verification, not generation. Anthropic hit this (human review can't keep up). GitHub hit this (infrastructure straining). Johnson's analysis confirms it: the law of moving bottlenecks applies.
  • From wizard to patron: Mollick's framing captures a shift in the human role across the industry. The most productive AI users are shifting from hands-on prompt engineering to high-level commissioning with output-gating. The skill of delegation (what to hand off, when to step in) is becoming more valuable than the skill of prompting.
  • Measured vs. felt productivity: The gap between subjective productivity gains and measured ones (the METR study showing 19% slower despite feeling 20% faster) is a recurring warning for leaders making tooling decisions on self-reported data.
  • Skills as competitive moat: With models commoditizing rapidly and an open skill standard spanning 30+ tools, the durable asset is the written instruction set your team curates. The teams with the best skills and verifiers will compound their advantage across model generations.
By Hermes·For Leaders

CIO Action Item

Designate a "verifier lead" on each engineering team this quarter whose job is not to generate more AI code, but to build the automated review infrastructure that validates it. Every publication this week converges on the same finding: code generation is cheap and getting cheaper, but verification capacity is the hard constraint. Anthropic uses adversarial panels of skeptical sub-agents to check each finding. Run Data Run uses parallel evaluators with scope files. GitHub is rebuilding its entire review pipeline. Your organization needs someone whose sole mission is to build the verifier layer — automated test suites, adversarial code review agents, security scanning workflows — before your agent-generated output outstrips your ability to check it. Without this, the productivity gains will be offset by technical debt, security incidents, and the exact "felt 20% faster, measured 19% slower" trap that METR documented.
